## 2. 주요 조사 및 분석 결과 (Analysis)

### [Mapping] BoardMaster SORT_ORDER 0 출력 이슈
- **현상:** `COMMON_CODE_GROUP`과 JOIN 하여 가져오는 `SORT_ORDER` 값이 모델 매핑 시 `0`으로 초기화됨.
- **원인 분석:** 
    1. **순서 의존성:** 현재 MyBatis `<constructor>` 매핑이 파라미터 순서(8번째)에 의존하고 있어, Lombok 생성자 순서와 어긋날 가능성 존재.
    2. **기본값 매핑:** 매핑 실패 시 Java primitive type의 기본값(`0`)이 할당되었을 가능성.
- **해결 제안:** MyBatis `<arg>` 태그에 `name` 속성을 추가하여 이름 기반 매핑으로 전환하거나, `@Param` 어노테이션을 생성자에 명시적으로 사용.

### [Bug] existsByBoardNameExceptMe ClassCastException
- **에러 로그:** `com.sqld_board.sqld.model.board.BoardMaster cannot be cast to java.lang.Boolean`
- **원인:** `BoardMaster.xml`의 `resultType`이 `BoardMaster`로 잘못 설정됨. Java 인터페이스는 `Boolean`을 기대하나 MyBatis가 객체를 반환하려다 형변환 오류 발생.
- **해결 방안:** XML의 `resultType`을 `boolean`으로 수정.

### [Architecture] RESTful 설계 원칙 재확인
- **Inquiry:** 상세 조회 시 `@PathVariable` vs `@RequestParam` 선택.
- **결정:** 고유 자원 식별(Identification)을 위해 `@PathVariable`을 사용하는 것이 프로젝트 표준 및 RESTful 관례에 부합함을 확인.
