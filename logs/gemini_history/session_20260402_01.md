## 2. 주요 작업 및 결정 사항 (Decisions)

### [Admin Features] 휴지통 및 데이터 관리
- **휴지통 조회 API:** `DELETE_YN = 'Y'`인 게시글을 조회하는 기능 구현. 페이징 성능 최적화를 위해 인라인 뷰(Inline View)와 전문 검색(`MATCH...AGAINST`) 적용.
- **댓글 카운트 로직:** 휴지통 내 게시글의 댓글 수는 `DELETE_YN` 조건 없이 전체 카운트하여 관리자에게 데이터의 원래 규모를 보여주도록 설정.
- **물리 삭제 배치:** 삭제 후 30일이 경과한 데이터를 자동으로 영구 삭제하는 MyBatis 쿼리(`deleteOldSoftDeletedBoards`) 작성 및 `Admin.xml` 통합.

### [Security] 권한 위계 및 보안 강화
- **SUPER_ADMIN 역할 도입:** 시스템의 최상위 권한자를 구분하여 고위험 작업(회원 강퇴, 관리자 승격/강등)을 전담하도록 설계.
- **권한 변경(Toggle) 보안 로직:** 
    - **자기 자신 변경 불가:** 관리자가 스스로의 권한을 낮춰 시스템에서 튕겨 나가는 사고 방지.
    - **위계 보호:** 일반 `ADMIN`은 다른 `ADMIN`이나 `SUPER_ADMIN`을 강등시킬 수 없으며, 오직 `USER`를 `ADMIN`으로 승격시키는 것만 가능하게 제한.
- **Spring Security 연동:** `CustomSecurityConfig`에서 `hasAnyRole`을 통해 `SUPER_ADMIN`의 접근 권한을 명시하고, `@EnableMethodSecurity`를 활성화하여 컨트롤러 수준의 세밀한 제어 구현.

### [System Optimization] 응답 표준화
- **성공 응답 데이터 포함:** `ResponseHandler` 및 `Response` 클래스를 확장하여 성공 메시지뿐만 아니라 변경된 최신 데이터(예: 변경된 권한 정보)를 프론트엔드에 즉시 전달하도록 개선. 이를 통해 프론트엔드에서 페이지 새로고침 없는 UI 업데이트 가능.
