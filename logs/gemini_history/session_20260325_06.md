## 2. 주요 작업 및 결정 사항 (Decisions)
- **[Error Fix] 401 Unauthorized (SecurityContext Null):**
    - 원인: `CustomSecurityConfig.java`에서 `/api/board/**`를 전체 `permitAll()`로 설정하여, 시큐리티가 인증 정보를 생성하지 않음.
    - 해결: 조회/검색 API만 `permitAll()`로 두고, 데이터 변경 API(스크랩 삭제 등)는 `authenticated()`로 명시적 분리.
- **[Design Choice] 이중 보안 체계(Defense in Depth) 확립:**
    - 정책: 시큐리티의 현관 보안(`authenticated`)과 컨트롤러의 방문 보안(`if(user == null)`)을 모두 유지하기로 결정.
    - 효과: 설정 실수로 인한 권한 유출 방지 및 타입 안정성 확보.
- **[Bug Fix] Security Config Typo:**
    - 수정: `"/api/board/l`ist/**"` 경로의 백틱(`) 오타 수정 완료.
