[전체 API 및 기능 구현 명세서] (최종 업데이트: 2026-03-25)

1. 개요
   - 게시판(SQLD 학습/가입인사/공지) 및 회원 관리 시스템 전체 API 명세.
   - MySQL 8.0 및 고성능 전문 검색(FTS) 엔진 기반.

2. 공통 설정
   - Base URL: http://localhost:8881
   - 응답 구조: { "success": boolean, "code": int, "msg": string, "result": { "data": ... } }
   - 인증 방식: Header (Authorization: Bearer {token}) / Cookie (refresh-token)

3. 회원가입 및 인증 API (Sign / Auth)
   - [POST] /api/common/signIn : 로그인 (통계 정보 및 프로필 포함 반환)
   - [POST] /api/common/signUp : 회원가입 (초기 상태 'N')
   - [POST] /api/common/logout : 로그아웃 (쿠키 및 토큰 파기)
   - [POST] /api/token-refresh : 토큰 재발급 (세션 유지 및 최신화)
   - [POST] /api/common/send-code : 가입용 이메일 인증번호 발송 (중복 가입/인증 체크)
   - [POST] /api/common/verify-code : 가입용 이메일 인증번호 확인
   - [GET]  /api/common/check-id : 아이디 중복 확인
   - [GET]  /api/common/check-name : 닉네임 중복 확인
   - [POST] /api/common/pass-change/request : 비밀번호 변경 인증번호 요청 (ID+이메일 일치 확인)
   - [POST] /api/common/pass-change/verify : 비밀번호 변경 인증번호 확인
   - [PATCH] /api/common/pass-change : 비밀번호 최종 변경 (보안 토큰 기반)
   - [PATCH] /api/member/profile-image : 프로필 이미지 경로 영구 저장
   - [DELETE] /api/member/deleteMember/{userId} : 회원 탈퇴 및 강퇴 (본인/관리자 구분 응답)

4. 게시판 기능 API (Board)
   - [GET]  /api/board/list : 전체 게시글 목록 조회
   - [GET]  /api/board/list/{boardId} : 게시글 상세 조회 (작성자 프로필, 추천 여부 포함)
   - [GET]  /api/board/list/paging : 페이징 목록 조회 (CATEGORY_ID, userId 필터링 지원)
   - [GET]  /api/board/searchContent : 통합 전문 검색 (제목+본문, boardCode 필터링 지원)
   - [POST] /api/board/list/write : 게시글 등록 (multipart/form-data, 가입인사 필수 체크)
   - [PUT]  /api/board/list/{boardId} : 게시글 수정 (제목, 본문, 카테고리, 태그, 파일 추가)
   - [DELETE] /api/board/list/{boardId} : 게시글 삭제
   - [POST] /api/board/upload : CKEditor 전용 실시간 이미지 업로드
   - [POST] /api/board/like : 게시글 추천 토글 (중복 추천 방지)
   - [PUT]  /api/board/countView : 게시글 조회수 수동 증가
   - [DELETE] /api/board/deleteMyScrapPage : 마이페이지 스크랩 삭제 (ScrapDeleteRequest DTO 기반)

5. 댓글 기능 API (Comment)
   - [POST] /api/board/writeComment : 댓글/대댓글 작성 (userId 기반 저장)
   - [GET]  /api/board/readComment : 특정 게시글 댓글 목록 조회 (작성자 프로필 포함)
   - [PUT]  /api/board/modifyComment : 댓글 수정 (본인 확인)
   - [DELETE] /api/board/deleteComment/{commentId} : 댓글 삭제 (대댓글 유무에 따른 마스킹 또는 연쇄 삭제 처리)

6. 관리자 전용 API (Admin)
   - [GET]  /api/admin/getMemberList : 전체 회원 리스트 조회 (활동 통계 및 접속시간 포함)

7. 핵심 비즈니스 규칙
   - 'N' 상태 사용자: 가입인사('G') 게시판에만 글쓰기 가능.
   - 등급 자동 승격: 가입인사 작성 완료 시 즉시 'Y' 상태로 전환.
   - 검색 최적화: MySQL 8.0 N-gram 파서를 통한 한글 검색 품질 극대화.
   - 데이터 정합성: 모든 저장 로직은 USER_ID(로그인ID)와 MEMBER_ID(고유키)를 이중 관리.

8. 인덱스 설정 (DB 작업 필수)
   - ALTER TABLE BOARD ADD FULLTEXT INDEX ft_index (TITLE, CONTENT) WITH PARSER ngram;

9. 시스템 관리 및 작업 규칙 (Gemini CLI 전용)
   - [규칙 1] 모든 작업은 사용자의 승인하에 진행.
   - [규칙 2] 질문 답변 시 임의 작업 준비/진행 금지.
   - [규칙 3] 사용자 확인 없이 임의 파일 삭제 금지.
   - [규칙 4] 누락된 파일 및 영향도 철저 검수.
   - [로그 시스템] logs/gemini_history/ 폴더에 매 세션 작업 기록 보관.
   - [마스터 가이드] GEMINI.md 파일을 통해 최신 상태 상시 동기화.
